PANEL DE CONTENIDO

Edita el sitio sin tocar código.

El panel recomendado es Pages CMS. Trabaja directamente sobre tu repositorio de GitHub y guarda cada cambio como una versión recuperable.

Acceso

1. Entra a app.pagescms.org e inicia sesión con GitHub.

2. Instala/autoriza Pages CMS únicamente para el repositorio de este sitio.

3. Abre el repositorio. El archivo .pages.yml ya está incluido.

4. Desde el panel tendrás: Datos generales, Proyectos, Recursos, Imágenes y Documentos.

5. Al guardar, Pages CMS hace el cambio en GitHub. GitHub Pages vuelve a publicar el sitio automáticamente.
